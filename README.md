# Moved

This comparison page is now part of **InChI Specifications**:
https://cm-beilstein.github.io/InChI-specs/ (source: https://github.com/cm-beilstein/InChI-specs).

Per feature it has the specification, an explanation for chemists, old-vs-new examples,
the step-by-step workflow, datasets and kick-off documents, with a comment thread on every
molecule. Molecule IDs are unchanged (e.g. molecule 55 is `#m55` on its feature's
examples page).

The old page, its explanation and workflow pages now redirect there, including the
section anchors (`#enhanced`, `#allenes`, `#ez`, `#atropisomers`, `#meso`). The generator
(`tools/`) and its data (`data/`, `svg/`) remain here for history only; the maintained
copies live in InChI-specs.
